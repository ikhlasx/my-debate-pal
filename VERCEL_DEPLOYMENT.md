## Quick Deploy (5 Minutes)

### Method 1: Deploy via Vercel Dashboard (Recommended)

1. **Go to Vercel**
   - Visit [vercel.com](https://vercel.com)
   - Click "Sign Up" or "Log In"
   - Connect with your GitHub/GitLab/Bitbucket account

2. **Import Your Project**
   - Click "Add New..." → "Project"
   - Find your repository: `my-debate-pal`
   - Click "Import"

3. **Configure Build Settings**
   - **Framework Preset**: Vite ✅ (Auto-detected)
   - **Root Directory**: `./` (leave as is)
   - **Build Command**: `npm run build` ✅ (Auto-filled)
   - **Output Directory**: `dist` ✅ (Auto-filled)
   - **Install Command**: `npm install` ✅ (Auto-filled)

4. **Deploy**
   - Click "Deploy"
   - Wait 1-2 minutes
   - Done! 🎉

Your app will be live at: `https://your-project-name.vercel.app`

---

### Method 2: Deploy via Vercel CLI

```bash
# Install Vercel CLI globally
npm install -g vercel

# Navigate to your project directory
cd my-debate-pal

# Login to Vercel

# What's your project's name? my-debate-pal
# In which directory is your code located? ./
# Want to override the settings? [n] n

# Deploy to production
vercel --prod
```

## Important: Enable Enhanced Features

Your app has two versions:
- **Index.tsx** - Original version (currently active)
- **IndexEnhanced.tsx** - Full-featured version (recommended)

### To Use Enhanced Version:

**Option 1: Update the Router** (Recommended)

Find your routing file (likely [src/App.tsx](src/App.tsx)) and update:

```tsx
// Before
import Index from "@/pages/Index";

// After - Option A: Replace import
import Index from "@/pages/IndexEnhanced";

// After - Option B: Rename the import
import IndexEnhanced from "@/pages/IndexEnhanced";
// Then use IndexEnhanced in your routes
```

**Option 2: Rename the File**

```bash
# Backup original
mv src/pages/Index.tsx src/pages/IndexOriginal.tsx

# Rename enhanced version
mv src/pages/IndexEnhanced.tsx src/pages/Index.tsx
```

**After making changes:**
```bash
# Commit and push
git add .
git commit -m "Enable enhanced notification features"
git push

# Vercel will auto-deploy in ~2 minutes
```

## Troubleshooting

### Issue: Build Fails

**Check the build logs:**
1. Go to Vercel Dashboard
2. Click on the failed deployment
3. Read the error message

**Common fixes:**
```bash
# Locally test the build
npm run build

# If it fails, fix errors shown
# Then commit and push
git add .
git commit -m "Fix build errors"
git push
```

### Issue: Service Worker Not Working

**Solution:**
- Service workers require HTTPS ✅ (Vercel provides this automatically)
- Check browser console for errors
- Clear cache: DevTools → Application → Clear Storage → Clear site data
- Hard refresh: `Ctrl+Shift+R` (Windows) or `Cmd+Shift+R` (Mac)

### Issue: Notifications Not Showing

**Checklist:**
- [ ] HTTPS enabled (check URL starts with `https://`)
- [ ] Permission granted (check browser address bar for icon)
- [ ] Service worker registered (DevTools → Application tab)
- [ ] Not in incognito/private mode
- [ ] Browser supports notifications (Chrome, Firefox, Safari 14+)

### Issue: App Loads Blank Page

**Fix:**
1. Check build output directory is `dist`
2. Verify vite.config.ts is correct
3. Check browser console for errors
4. Ensure all imports use `@/` alias correctly

### Issue: 404 on Refresh

Vercel should handle this automatically with Vite, but if not:

Create `vercel.json`:
```json
{
  "rewrites": [
    { "source": "/(.*)", "destination": "/index.html" }
  ]
}
```

   ```json
           }
         ]
       }
     ]
   }
   ```

## Automatic Deployments

### Production Deployment
- Every push to `main` branch → auto-deploys to production
- URL: `https://your-project.vercel.app`

### Preview Deployments
- Every push to other branches → creates preview URL
- URL: `https://your-project-git-branch-name.vercel.app`
- Perfect for testing features before merging

### How to Set Up Branches

```bash
# Create a feature branch
git checkout -b feature/new-feature

# Make changes and commit
git add .
git commit -m "Add new feature"

# Push to GitHub
git push origin feature/new-feature

# Vercel automatically creates a preview deployment
# Check Vercel Dashboard for the preview URL

# When ready, merge to main
git checkout main
git merge feature/new-feature
git push origin main

# Automatically deploys to production
```

## Mobile App (PWA) Setup

Your app can be installed as a Progressive Web App!

### Enable PWA Features

Create `public/manifest.json`:
```json
{
  "name": "Debate Tracker",
  "short_name": "Debate",
  "description": "Track debate sessions between partners",
  "start_url": "/",
  "display": "standalone",
  "background_color": "#ffffff",
  "theme_color": "#3b82f6",
  "icons": [
    {
      "src": "/icon-192.png",
      "sizes": "192x192",
      "type": "image/png"
    },
    {
      "src": "/icon-512.png",
      "sizes": "512x512",
      "type": "image/png"
    }
  ]
}
```

Add to `index.html`:
```html
<link rel="manifest" href="/manifest.json">
<meta name="theme-color" content="#3b82f6">
```

Users can now "Add to Home Screen" on mobile! 📱
